-HOW TO ADD THE THEME-
______________________


1. Copy this link: https://raw.githubusercontent.com/NucleanYT/Ven/main/theme.json

2. Open Revenge
3. Go to settings
4. Select Themes
5. Press the + icon
6. Paste the link.

-------------------------------
Don't have Revenge? Do this! 👇



________________________
-HOW TO INSTALL REVENGE-
________________________

(Note: Revenge is Android-only and Android 12+ is recommended) 

1. Go to this Repository: https://github.com/revenge-mod
2. Scroll to the Assets section
3. Select the first option
4. Open the downloaded file and select Install (or Download)
5. Open the Revenge Manager
6. Install Revenge
7. if Play Protect wants to do a scan don't let it. (Mandatory)
